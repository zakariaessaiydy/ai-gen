# Background prompts — paste into the free Gemini app (gemini.google.com)

How to keep every image in the SAME style:

1. Open a new Gemini chat for each image.
2. **Attach the reference image(s)** listed under the prompt (they are in `media/library/backgrounds/` — download them from GitHub once).
3. Paste the prompt exactly. Then save the image with the **file name** shown and upload it to `main` (any folder is fine — I sort them).

If a result has a character, text, or something big in the middle, just ask Gemini: *"same image but remove X and keep the middle empty"*.
